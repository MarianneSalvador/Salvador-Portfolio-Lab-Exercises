Bubble Sort

Bubble Sort repeatedly compares adjacent values and swaps them when they are out of order. It repeats until the list is sorted.

Insertion Sort

Insertion Sort builds a sorted portion one value at a time by inserting each value into its correct position.

Selection Sort

Selection Sort repeatedly selects the smallest value from the unsorted portion and moves it into the sorted portion.

Quick Sort

Quick Sort chooses a pivot and partitions the other values around it, then sorts those partitions recursively.

Merge Sort

Merge Sort divides the list into smaller parts, sorts them, then merges the sorted parts.

Heap Sort

Heap Sort repeatedly removes the largest value from a max-heap and places it at the end of the list.
